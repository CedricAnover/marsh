# v0.3.9 — UX & Extension Convergence

## Summary

v0.3.9 adds a thin application and extension boundary around the canonical
Marsh workflow/runtime contracts.

## Delivered

- Read-only CLI inspection with deterministic human and JSON output.
- Stable package version reporting through the installed distribution metadata.
- Deterministic extension discovery through the `marsh.extensions` entry-point group.
- Compatibility gating through the `Marsh-Extension-Contract` metadata field.
- Secret-safe diagnostics for credential-like fields and authorization values.
- Cross-version conformance through CircleCI for Python 3.10, 3.11, and 3.12.
- GitHub Actions validation for the repository's Linux, Windows, Docker, and SSH smoke paths.
- CLI, extension, and release documentation.

## Compatibility boundary

The release keeps these concerns distinct:

1. Marsh package version.
2. Extension contract version.
3. Workflow IR version.
4. Extension package version.

Only the extension contract controls activation compatibility in v0.3.9.

## Non-goals

v0.3.9 does not introduce a second workflow engine, new scheduler semantics,
remote execution, or a generalized plugin framework.

## Verification

The release is accepted only when the full CircleCI and GitHub Actions evidence
is green and the final `main` and `develop` refs are synchronized.
