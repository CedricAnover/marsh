# v0.3.6 — Workflow IR & Configuration Boundary

## Highlights

- Established the versioned `marsh.workflow/v1` canonical Workflow IR.
- Added explicit `OperationRef` values for portable top-level Python callables.
- Added deterministic canonical JSON serialization and explicit rejection of unsupported runtime values.
- Added provider-neutral Machine, Provider, Scheduler, and Policy configuration boundaries.
- Preserved legacy authoring normalization when no IR schema envelope is present.
- Added cross-process reconstruction coverage and configuration boundary tests.
- Documented the IR contract, security boundary, compatibility behavior, and architecture.

## Compatibility

The existing runtime and scheduler model remains unchanged. The IR is a semantic representation and serialization boundary, not a second execution engine.

Unsupported schema versions, non-portable callables, non-finite numbers, bytes, and arbitrary runtime objects fail explicitly.
