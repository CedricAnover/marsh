# v0.3.3 — Kernel Contract Stabilization

## Summary

v0.3.3 stabilizes the smallest Marsh execution kernel before further provider and concurrency work.

## Contract changes

- `plan_workflow()` is the canonical dependency-planning semantic owner.
- `validate_workflow()` delegates to canonical planning instead of maintaining a second topological implementation.
- Deterministic task order and initial readiness are regression-tested.
- Scheduler and Machine replacement are covered by conformance tests.
- Lifecycle, failure, timeout, cancellation, dependency-skip, and fail-fast semantics are regression-tested.
- Modern namespace compatibility remains covered without removing legacy APIs.
- Observer failures remain non-authoritative and cannot change execution outcomes.

## Reliability fix

- Hardened Docker container cleanup against auto-remove races that can surface as stale-container `404 Not Found` errors.
